## 2. 未执行的四个原因

### (a) 期权市场已休市
GOOGL 是**个股期权**, 交易至 **16:00 ET** 收市 (不是 ETF 期权的 16:15)。现 **16:28 ET**。
任何单都只能排到**次日开盘**, 届时成交价是明天跳空后的价, 不是现在看到的任何数字。

### (b) 六个参数全缺, 每一个都决定这是完全不同的交易 (红线2)
`GOOGL` 还是 `GOOG`? **call 还是 put**? 行权价? 到期日? 张数? 限价?
这六项就是策略本身。我自己填 = 「基于自己的市场观点新增订单」, 红线2 明令禁止。
⚠️ 尤其是**方向**: 标的刚跌 8.6%, call 是赌反弹、put 是赌继续跌 —— 我不替用户选方向。

### (c) 引擎对 GOOGL 是**三重否决**, 没有任何引擎输出可依

GOOGL 同时在 RSI-2 100 股池**和**实盘周call 池里 (GOOG 只在前者), 两条轨道都不会买它:

| 闸 | 判定 |
|---|---|
| **入场信号** | rsi2 = **75.31** (需 < 10) 且收盘 325.63 **低于** SMA200 341.20 (需在其上) → **两个条件都不成立**。GOOGL 现在不是超卖, 是**超买** (rsi2 75), 而且已在 200 日线之下 |
| **财报黑窗** (`earnings_blackout_days=7`) | 财报日 = 今天 → `days_to_earnings = 0` → `0 <= 0 <= 7` → **拦** |
| **近 20 日异动** (`max_daily_move_pct=8.0`) | 盘后 **−8.64%** > 8.0%, 且是**下跌**跳空 (`earnings_gap_up_exempt` 只豁免上涨方向) → **拦**, 且该根异动未来约 **20 个交易日**持续拦 |

GOOG 同理 (rsi2 76.50, 收盘 322.35 < SMA200 339.27, 盘后 −8.52%)。

### (d) 实盘期权轨道形态只认 call
`weekly_calls.py:_pick_contract` 硬过滤 `meta['type'] != 'C'` —— **引擎做不出 put**。
且 Robinhood API 对多腿 400 拒, 实盘形态必须 `single`。
即便用户想要 put, 那也只能由用户在 App 手工下, 或先改引擎 (属红线2 禁区)。
