## 📌 更正我昨日战报里的一个数: BNY 时间止损不是"还剩 3 天"而是"**还剩 3 个交易日**, 口径不同

昨日战报写「BNY 时间止损还剩 3 天 (已持 7 个交易日)」。我今早按日历工作日重算得到
「已持 8 天、剩 2 天」, 两个数不一致, 于是去查了引擎的真实口径:

`scripts/signals.py:107-108`
```python
def trading_days_since(dates, since_date):
    return sum(1 for d in dates if d > since_date)
```

→ 计的是**严格晚于 `entry_date` 的实际 bar 数** (用真实交易日, 自动排除假日),
触发条件 `>= max_holding_days (10)`。**不含建仓日本身**。
