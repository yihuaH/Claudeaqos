# 研究: 盘前主跑 (15:30 ET) 是否值得复活 — 完整三段量化

**起因**: 用户 2026-09-10 两次表示「今天下午就可以执行」「17:45 主跑后我就可以执行」。
经澄清, 主跑后立刻执行**没有收益** (市场已收盘 + 出场回款次日 09:30 才到账, 券商在**下单时刻**
校验购买力 → 排单到次开一样吃不到)。用户的空闲真正能换到的只有一条路: **把整个循环压进开市时段**,
即盘前主跑。本文量化它值不值。

**授权状态**: **纯研究, 未做任何改动**。推进方式待用户决定。
(2026-07-24 该窗口因平台会话频繁挂起而退役, 见 CLAUDE.md 轨道表。)

**方法**: 复现引擎口径 (Wilder RSI-2 全历史平滑 / 入场 rsi2≤10 & close>SMA200 /
出场 rsi2≥65 & close>sma5 | 7% 止损 | 10 日时间止损)。日线自 2025-01-01 (让 SMA200 生效),
盘中 15 分钟线 (Alpaca SIP) 取 15:30 (信号价) 与 15:45 (执行价代理)。
研究区间 2026-03-16 → 09-09 (全程 EDT), 池 = ETF 8 + universe.json 100 = 108 只,
样本 13,284 个 (日,标的) 对。脚本: `scratchpad/preclose.py` / `preclose_pnl.py` /
`exit_fidelity.py` (会话内, 未入库)。

## 1. 入场信号保真度 — 19% 不一致, 但全是边缘票

| | |
|---|---|
| 收盘口径信号 | 956 |
| 15:30 口径信号 | 929 |
| 两者都有 | 845 |
| 只有收盘有 (盘前**漏掉**) | 111 = 收盘信号的 11.6% |
| 只有 15:30 有 (盘前**多买**) | 84 = 15:30 信号的 9.0% |
| **Jaccard 重合度** | **81.2%** |

分歧全部卡在阈值上: 漏掉那批 rsi2 中位 9.1(收盘) vs 11.2(15:30); 多买那批 11.6 vs 8.9。
推手是最后 30 分钟的价格漂移 (中位 ∓0.4%)。

15:30→收盘的全样本漂移: 均值 −0.003% · 中位 −0.003% · 标准差 0.467%
(|漂移|>0.5% 占 20.9%, >1.0% 占 3.9%) —— **无系统性偏差, 纯噪声**。

两组都明显弱于共有组 —— **边缘信号本就是最差一档, 一漏一补基本对冲**:

**信号质量净差 = −0.022 pp/笔, 95% bootstrap [−0.342, +0.311] → 区间横跨 0, 无可测差异。**

## 3. 入场执行价 — 收益全在这里

| 方案 | 成交价 vs 引擎信号价 |
|---|---|
| 现行 (隔夜 → 次日盘中 09:45–12:00) | **+0.350%** (n=953, 见 `2026-09-10-exec-window.md`) |
| 盘前 (15:30 信号 → 15:45 成交) | **−0.054%** (n=929) |

**净差 +0.404 pp/笔, 对盘前有利。** 这一项是**机械性的**, 不是统计推断 ——
均值回归买超卖票, 隔夜那一段的反弹是策略本身在走, 晚 18 小时进场就是少吃这一段。

## 4. 出场保真度 — 完全不敏感 (用户 2026-09-10 要求补测)

同一入场信号 (n=885 配对), 只换出场口径:

| 出场口径 | 均值/笔 | 中位 | 胜率 | p10 |
|---|---|---|---|---|
| 回测口径 (收盘判 / 收盘成交) | +1.608% | +1.880% | 78.9% | −2.17% |
| **现行实况** (收盘判 / 次开成交) | +1.615% | +1.766% | 75.9% | −2.86% |
| **盘前方案** (15:30 判 / 15:45 成交) | +1.650% | +1.864% | 80.3% | −2.04% |

| 对比 | 净差 | 95% bootstrap |
|---|---|---|
| 盘前 − 现行 (出场端净差) | +0.034 pp/笔 | [−0.094, +0.160] |
| 现行 − 回测口径 (隔夜出场漂移的代价) | +0.007 pp/笔 | [−0.098, +0.118] |
| 盘前 − 回测口径 | +0.042 pp/笔 | [−0.041, +0.127] |

**三个区间全部横跨 0 —— 出场端怎么改都一样。**

机制解释: 出场闸不像入场闸那样贴边。`rsi2≥65` 触发时通常已远超阈值,
`7% 止损` 是宽阈值, 两者都很少正好卡在 15:30→收盘那 ±0.47% 的漂移里。
隔夜出场漂移同理 —— 方向随机, 均值为 0。

> 附带 (**未达显著, 不作为依据**): 盘前口径的胜率 80.3% vs 现行 75.9%, p10 −2.04% vs −2.86%。
> 同日 15:45 出场避开了出场方向的隔夜跳空, 尾部似乎更浅。均值差不显著, 样本再多才能定论。

## 5. 总账

| 环节 | 净差 (盘前 − 现行) | 95% 区间 | 显著 |
|---|---|---|---|
| 入场信号质量 | −0.022 pp/笔 | [−0.342, +0.311] | ❌ |
| **入场执行价** | **+0.404 pp/笔** | 机械性 | ✅ |
| 出场信号 + 执行 | +0.034 pp/笔 | [−0.094, +0.160] | ❌ |
| **合计** | **≈ +0.42 pp/笔** | | |

对照基准均值 +1.36~1.62%/笔 → **相对提升约 26~31%**。
与 playbook 那句「异步入场保留 ~75–80% 收益」独立互证。

**结论: 三段里只有一段有钱, 就是入场执行价; 另两段是平局。
盘前主跑的全部价值 = 不跨夜进场。**

## 6. 唯一未解的风险: 运维 (**完全没有数据**)

2026-07-24 退役的原因不是收益, 是**平台会话在该窗口连续两天被 worker 重启挂起**。
跑挂了不只是没买 —— **出场卖单也不会下**, 当日风险敞口原样留着。
这是 +0.42 pp/笔换不来的尾部风险, 且本文一个数字都没有。

**降险思路 (未实施): 拆分主跑。** 当初脆是因为整个主跑塞进 35 分钟。真正时间敏感的只有一小段:

- **盘前关键路径 (15:20–15:55)**: `get_portfolio` + `get_equity_positions` → 日线 →
  `signals.py` → 出场卖单 place + 写 pending。估计 3–5 分钟。
- **留在 17:45**: 期权双轨、纸面轨道、price_check、journal、账本回写、周度筛选 —— 一分钟都不敏感。

关键路径从「整个主跑」缩到几分钟, 挂起暴露面小一个数量级。**但耗时与挂起率仍是估计值, 未实测。**
